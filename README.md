# Птичка - фотоцентр в Сочи

Сайт для сети фотоуслуг: три точки в центре Сочи, фото на документы,
печать, копицентр, подарки и сувениры.

**Живая страница:** https://pipiskidev.github.io/ptichka/

## Что внутри

Один самодостаточный файл `index.html`. Внешних библиотек нет, стили внутри,
скрипт на два обработчика. Шрифт с Google Fonts, фотографии с CDN Яндекса.

- первый экран во всю ширину с настоящим фасадом и вывеской;
- четыре главные цены крупно, сразу под первым экраном;
- три точки с маршрутами;
- девять работ из их залов и витрин, у каждой настоящая цена;
- полный прайс: 23 группы, 74 позиции, с поиском по строкам;
- тёмная тема, липкая панель связи на телефоне.

## Откуда данные

**Ничего не выдумано.** Прайс снят с их страницы цен на Яндекс Картах,
фотографии - из их собственной карточки, каждая проверена запросом.

Восемь стоковых кадров и один с устаревшими ценниками исключены поимённо:
именно от них страница начинает пахнуть конструктором.

## Как пересобрать

    python ../tools/ptichka_sayt.py

Сборщик читает `leads/ptichka-prays.json` и `leads/ptichka-foto.json`
и складывает готовый `index.html` сюда.
